# ハルナス眼科カルテ デモ台本

あさおか眼科向けのデモ用。登場する患者・医療機関はすべて架空で、実在の人物とは関係ない。

- 所要時間: 約20分（質疑を除く）
- 画面: PC 1台（受付・医師役）＋ iPad 1台（シェーマ・視能訓練士役）があると伝わりやすい
- データ投入（当日の朝に実行。予約は「実行した日」に入る）:

```bash
# gcloud にログインしているアカウント（info@halunasu.com）の認証情報を、この実行だけで使う
export GOOGLE_APPLICATION_CREDENTIALS="$HOME/.config/gcloud/legacy_credentials/info@halunasu.com/adc.json"
node scripts/seed_eye_demo.mjs --env stg --organization-code halunasu-internal-stg            # 確認（dry-run）
node scripts/seed_eye_demo.mjs --env stg --organization-code halunasu-internal-stg --apply    # 投入
```

何度実行しても患者・履歴は重複しない。2回目以降は「その日の予約」だけが追加される。

手元だけで見せる場合: `node scripts/dev_eye_stack.mjs --demo` と `npm run dev --workspace @halunasu/eye-web`（環境変数は runbook 参照）。

## 進行（約20分）

### 1. 受付（3分）— 医療事務の画面
1. 「受付」を開く。今日の予約が時刻順に並んでいる。
2. 見本 花子・試験 一郎の「受付する」を押す → 受付番号が付いて進捗ボードに移る。
3. 「当日受付」で予約なしの患者を受け付ける（例: 飛込 花子）→ 「患者登録」で登録まで。
4. 伝えること: **紙の受付票と呼び出し順の管理がこの1画面になる。** 誰がどれだけ待っているかも出る（30分を超えると枠が黄色）。

### 2. 検査（3分）— 視能訓練士の画面（iPad）
1. 見本 花子のカードで「検査開始」→「カルテ作成」。
2. 前回の方針・処方・所見・シェーマが引き継がれている。視力・眼圧は空欄（毎回測るため）。
3. 視力（R 0.9 / L 0.8）と眼圧（R 22 / L 17）を入れる → 右側に「前回から変わった所」が出る。21 mmHg 超えの印も出る。
4. 「検査終了」で診察待ちへ。
5. 伝えること: **検査結果を印刷して貼る作業がなくなる。** 将来は機器から自動で入る。

### 3. 診察（7分）— 医師の画面
1. 診察待ちのカードから「診察開始」→ カルテを開く。
2. **前回との比較**（右側）で、眼圧が 17→22 に上がったことを確認。
3. 患者ページの**経過**で、2年分の眼圧と点眼の追加時期を見せる。「いつ目薬を変えたか」がすぐわかる。
4. 方針を書き換える（例: 「眼圧上昇。アドヒアランス確認。次回視野」）。
5. 次回受診「12週後」→ **処方の本数の目安**（ラタノプロスト 84日×1回×両眼÷80滴＝3本）を確認して「反映」。
6. シェーマを iPad で少し描き足す（赤ペンで乳頭の陥凹など）。
7. 「確定する」→ v1 として保存。修正は理由付きで v2 になることも見せる。
8. 右側の「次回予約を取る」→ 12週後の日付が入った状態で予約。
9. 伝えること: **再診は「前回コピー＋変わった所だけ」が標準。** 本数と次回の日付は、毎回聞かなくても目安が出る。

### 4. 注射の患者（3分）
1. 試験 一郎の患者ページを開き、注射の履歴と間隔（4→6→8→6週）、視力の推移を見せる。
2. 伝えること: 将来は OCT の数値（網膜厚）もこの時間軸に並べ、前回との比較を画像で出す（判定はしない）。

### 5. 会計・終了（1分）
1. 「診察終了」→「会計済み」でボードから消え、「終了」に入る。
2. 伝えること: レセコン（医療事務ソフト）へは、次の段階で診療行為を送る。

### 6. まとめ（3分）
- 今日見せたもの: 受付〜診察〜次回予約までが1つの画面でつながる。
- 次の段階: 口頭からのカルテ下書き（AI）、検査機器の取り込み、レセコン連携。
- お願いしたいこと: 1週間の時間計測（記載時間・貼り付け・探す時間・本数確認）。

## 模擬診察の会話台本

デモで医師役・患者役を演じるとき、また将来の音声入力の試験に使う。

### A. 見本 花子（緑内障・再診）

> 医師: 見本さん、こんにちは。目薬はちゃんと続けられていますか。
> 患者: はい、朝と夜で2種類。でも夜のほうはたまに忘れます。
> 医師: 今日は右の眼圧が22で、前回の17より上がっています。夜の分を忘れると上がりやすいので、歯みがきの後など時間を決めましょう。
> 患者: わかりました。見え方は特に変わりません。
> 医師: 視力も右0.9、左0.8で大きな変化はありません。今日は視野検査もしましたが、結果は次回一緒に見ましょう。目薬はラタノプロストを1日1回、チモロールを1日2回、両眼で続けてください。次は12週後です。ラタノプロストは3本、チモロールは3本出しておきます。
> 患者: 3か月後ですね。

カルテに入る内容: 主訴「定期検査、夜の点眼をときどき忘れる」／眼圧 R22 L17／視力 R0.9 L0.8／方針「アドヒアランス指導。2剤継続。次回視野結果説明」／次回12週／処方 2剤（本数は目安から反映）。

### B. 試験 一郎（糖尿病黄斑浮腫・注射）

> 医師: 前回の注射から6週間です。右眼の見え方はどうですか。
> 患者: 前と同じくらいです。ゆがみは少しあります。
> 医師: OCTでは網膜の厚さが292で、むくみは引いています。視力も右0.7で保てています。今日も注射をして、次は8週間に延ばしてみましょう。
> 患者: 間隔が延びるのはうれしいです。血糖は内科で7.2まで下がりました。
> 医師: いいですね。内科の治療も続けてください。

カルテに入る内容: 視力 R0.7／眼底 R「浮腫なし CST 292μm」／処方 アフリベルセプト（右眼）／方針「注射。8週へ延長」／次回8週。

### C. 模擬 和子（白内障術後5週）

> 医師: 手術から5週間ですね。右眼はいかがですか。
> 患者: よく見えます。まぶしさもなくなりました。
> 医師: 裸眼で1.0、眼圧も13で問題ありません。ベタメタゾンは今日で終わりにして、ブロムフェナクだけあと2週間続けてください。左眼の手術はどうしますか。
> 患者: 右がよく見えるので、左もお願いしたいです。
> 医師: では次回、左眼の術前検査をしましょう。

カルテに入る内容: 視力 R1.0（裸眼）／眼圧 R13／処方 ブロムフェナク（右眼 1日2回 14日分）／方針「ステロイド終了。左眼手術希望、術前検査予約」／次回2週。

### D. 初診 太郎（飛蚊症・初診）

> 医師: 今日はどうされましたか。
> 患者: 3日前から右眼に黒い虫のようなものが見えます。光が走るような感じもあります。
> 医師: 散瞳して眼底を詳しく見ますね。…網膜に穴や剥がれはありません。後部硝子体剥離による飛蚊症です。
> 患者: 治療は必要ですか。
> 医師: 今は不要です。ただ、黒いものが急に増えたり、カーテンがかかったように見えたらすぐ来てください。念のため1か月後にもう一度眼底を見ます。

カルテに入る内容: 主訴「右眼の飛蚊症、光視症」／眼底 R「後部硝子体剥離 網膜裂孔なし」（シェーマ: 眼底）／病名「後部硝子体剥離（右眼）」／方針「経過観察。増悪時は即受診」／次回4週。

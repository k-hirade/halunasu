# 国内クリニック向け電子カルテのシェアと、公開されているUI資料の調査（2026-11-09時点）

目的: Halunasu eye の UI/UX（配色を除く）をお手本にする「最もよく使われている国内クリニック向け電子カルテ」を決める。そのために、利用シェアと、公開資料からどこまで UI を学べるかを調べた。
調査は公開情報だけで行った。ログイン、Bot チェックの回避、リーク資料の利用はしていない。会員限定やログインが必要なページは「非公開」と扱っている。

---

## 1. 市場シェア

### 1-1. 結論
- **全体（無床診療所、医師アンケートによる導入・購入シェア）**: 首位は **エムスリーデジカル（M3 DigiKar）** か **ウィーメックス Medicom シリーズ（Medicom-HRf / Medicom クラウドカルテ等）** のどちらか。どの調査を使うかで順位が入れ替わる。
- **クラウド型に限ると**: どの資料でも **M3 DigiKar が1位**で、ほかの製品と大きな差がある。
- **金額ベース**: Medicom が「診療所シェアNo.1」を掲げている（出典は富士経済、2024年実績）。
- ベンダー名入りのシェアを中立の立場で公表した一次統計（厚労省、JAHIS、矢野経済のプレス要約など）は見つからなかった。どの数字も、ベンダー自身かその関連媒体が出したものという利益相反がある。

### 1-3. 解釈
- **新規開業・買い替えのフロー（新しく導入する施設）**: M3 DigiKar が首位で、25〜28% 程度。
- **導入済みのストック（全体の台数）**: Medicom が首位の可能性が高い。PHC/ウィーメックスはレセコン時代からの大きな顧客基盤を持ち、累計導入台数は 217,101 台とされる。
- **クラウド型に限ると**: M3 DigiKar が明確に1位。2位以下は Medicom（ハイブリッドとクラウドカルテ）、CLIUS、movacal.net、CLINICS が続くが、いずれも数%規模。
- 「最もよく使われている」の定義（ストックかフローか、台数か金額か）で答えが変わる。ただ、2つの候補がどちらも1〜2位にいることは、すべての出典で一致している。
- Henry は病院向けなので、無床診療所の比較からは外した。キヤノン（LifeMark-SX の販売窓口）とラボテック（SUPER Clinic）は、いずれもシェアが 2% 未満。

## 3. 推奨: お手本にするのは M3 DigiKar（エムスリーデジカル）

理由:
1. **シェア（a）**
   - クラウド型では、どの出典でも1位（m3 調査で 25〜28%）。
   - 全体でも、m3 調査で1位、日経調査で2位。
   - 新規開業の 70% がクラウド型を選んでいる（矢野経済）。新しく開業する医師が最も多く触れているカルテは、ほぼ確実に DigiKar になる。
   - Halunasu eye はクラウド型で、運用費ゼロを目標にしている。同じクラウド型の首位製品なので、比較の対象としても適切。
2. **公開UI資料の深さ（b）**
   - 上位2社のうち、画面ごとの手順書（スクリーンショット付き、計 1,000 ページ超）と機能別の動画が誰でも見られるのは DigiKar だけ。
   - Medicom は首位を争っているが、マニュアルが契約者限定なので、公開資料だけでは UI を再現できない。
3. **構造の相性**
   - 画面は「受付一覧 → カルテ 3 ペイン（左＝患者情報タブ、中央＝SOAP 主訴所見と処置行為、右＝オーダー・セット検索）→ 会計送信」という Web アプリの構成で、Halunasu eye（Web）にそのまま当てはめやすい。
   - ORCA 連動版とレセコン一体型版の両方のマニュアルがあるので、「レセコンはアダプターで接続する」という Halunasu の方針に合わせて、ORCA 連動版の UI を主な参考にできる。

補足:
- CLINICS カルテはシェアが小さい（約2〜3%）が、ヘルプが最も細かく、眼科関連の記事もある。DigiKar の資料で足りない箇所（文書、予約、細かな操作の分岐など）を補う副資料として使うのがよい。
- 「最も使われている」を導入済み台数（ストック）で厳密に定義すると、Medicom が1位の可能性がある。ただし公開資料が乏しいので、お手本としては実用的でない。
- 他社 UI の参考は、画面構成、操作の流れ、用語のレベルにとどめる。アイコン、画像、文言をそのまま流用することは避ける。一般的な著作権・不正競争防止の観点からの注意で、法的に確認したものではない。

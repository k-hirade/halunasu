## 1. トークン / CSS
- 二重定義: 罫線 globals `#d8e1ea` vs shared `#e5e7eb`（shared が勝つ）、補助色 `#5b6b7f` vs `#5b6573`、本文 `--text #142131` と `--ink #111827`、アクセント `--teal #0f8f84`（ボタン）と `--accent #0d9488`（リンク）。フォント/行間は shared の Noto Sans JP / 1.6 が勝つ。
- globals 内の生 hex 48 種、角丸 6/8/10/12/999。
- font-size 11 段階（11〜22px）+ shared の rem 由来 4 段階。最多は 13px。
- 暗室は eye 側トークンのみ上書き。shared の `--ink`/`--card`/`--border`/ナビ白が残る。テーマ適用が useEffect 内のため `<a>` 遷移ごとに白フラッシュ。開発時は StrictMode 二重 effect でリロード時に解除される。
- ブレークポイント不統一（1400/1180/1100/900/720、shared 920）。768〜1180 のタブレット設計なし。

## 2. ページ別
- **ログイン**: 390px で訴求文が 500px を占めフォームが画面外。© がチェックリストに重なる。
- **ホーム**: 「本日の受診」がカルテ作成済み 1 件のみ（受付は予約 8 件）。サブタイトル「院長（管理者・医師）（管理者・医師）」重複。ナビ 1120px 中央 / 本文 1480px で左端がずれる。患者リストに最終受診・次回予約なし。
- **受付**: 5 列固定ボードが 768px で 3.5 列、390px で 1.5 列のみ可視、横スクロールの手がかりなし。患者名リンク 61x14px、全 43 操作要素が 44px 未満。「受付する/キャンセル/来院なし」が同格で並び誤操作リスク。空列の「—」1.56:1。
- **患者**: 文書日付 UTC。ファイル入力が英語（Choose File）。グラフ軸 11px。
- **エディタ**: 1440px で高さ 3,794px・操作要素 132（ファーストビュー 49）、768/1024 で 6,000px 超。11 セクション縦積み、折りたたみ/ジャンプなし。固定ヘッダーが画面の 20/27/35%。検査表の「今」ボタンが 768 で切れ、390 で表幅 732px。処方 1 剤 約 190px、ラベルなし数値欄。視力 22px 太字・眼圧 15px で不揃い。Tab 順が右裸眼→左裸眼→右矯正→左矯正→右 S/C/Ax…。「保存済み」は 12〜13px の緑文字のみ。チェックボックス 21〜24px 高。
- **暗室**: 上記。主訴 textarea だけ白い。
- **検査画面**: 390px で左眼列が見えない。「右眼を確認/左眼を確認」と「両眼の検査値を確認済みにする」が重複。
- **眼鏡処方**: 未確定でも印刷できる配置。用紙境界なし。
- **文書**: 発行日 UTC。本文が 634px の textarea 1 つ。
- **会計連携**: 空状態で無効ボタン 3 つと 1 行案内のみ。
- **設定**: 4,396px（390px で 7,746px）1 ページ、ページ内ナビなし。操作記録に `eye.document_viewed` と「カルテを閲覧」が混在、対象が `pat_613…` の ID。

## 3. 横断
- タイポグラフィ: 実表示は 13px 以下中心、最小 11px、スケールなし、tabular-nums なし。
- レスポンシブ: 1440/1280/1024 は横あふれなし、768 はボード・「今」ボタンが内部あふれ、390 は全ページあふれ（エディタ 427、設定 635、検査表 732、眼鏡表 686）。
- IA: ナビが `<a href>` で全ページ遷移。受付と受診一覧で当日患者が二重管理。戻るリンクの位置がページごとに違う。
- フィードバック: Do 処方の既定チェック、保存状態の控えめさ、全ページで hydration mismatch。
- 一貫性: 緑 2 色、ボタン高さ 8 種（32〜48px）、角丸 5 種。
- アクセシビリティ: 主ボタン 3.98、リンク 3.74、プレースホルダー 2.5、暗室 1.02。フォーカスリングが薄い（透明度 0.28）。良い点: aria-label / aria-current / aria-pressed / dialog ロール。
